LOCAL TOOLS + OPTIONAL SERVICES

1 · Cloud storage & backups Local export works

You can export a full project archive to this phone now. Automatic online sync needs a secure backend and authentication; this static site does not secretly upload your music.

Working now: manual archive download/import through My Library. Online backup: backend required.

2 · Collaborate with your friend Manual sharing works

Prepare a project archive containing supported session settings and audio, then share the downloaded file using your phone's share menu or a method you trust. A live shared session, private invitations and access permissions need a backend.

Do not put private unreleased music in a public repository. Anyone who receives the archive may be able to open its contents.

3 · Music services Open/import supported

Import audio you have permission to use with the Studio's Import beat/audio button. These shortcuts open music services; they do not connect your account or download streaming tracks.

Direct streaming-service integration requires provider-approved APIs and permissions.

4 · Account & device management Local device check works

This version has no sign-in account system. Run a device/browser check and optionally save a display name on this device only.

This does not create an account or sync identity between devices. Real sign-in and access control require a properly secured authentication backend.

5 · AI music tools Backend required

The connector below can send a task to a compatible server you control. Beat generation, vocal separation and AI mastering are not included automatically; provider availability and cost vary.

Use the AI endpoint section below only after you have a real HTTPS service. Never paste private API keys into this public HTML or GitHub repository.

AI, cloud & Android

CONNECT YOUR SERVICES

AI music / stem separation connector

AI music generation and source separation require an AI provider or your own backend. Keep API keys on a server—never paste secret keys into this HTML file.

This button only works when you provide a compatible server endpoint that accepts POST multipart/form-data and returns JSON with a result URL or message. No AI service is included by default.

Cloud backup & collaboration

For secure cloud saving, sign-in and shared sessions, connect a backend you control. This sends project metadata and optional audio file to your endpoint; it does not create an account system on its own.

Use HTTPS and authentication on your backend. Never use a public endpoint that allows anyone to read or overwrite projects.

Install on Android

If hosted on HTTPS, open this site in Chrome and use ⋮ → Add to Home screen / Install app. That creates a home-screen web app; it is not an APK. A signed APK/AAB requires an Android wrapper/build process such as Capacitor and Android build tools.

If Chrome does not show an install prompt, use its menu. This single HTML file cannot independently produce a signed APK.
